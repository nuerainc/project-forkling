Fix the `running_sum(arr)` function in `buggy.py`. Given a list of
numbers, return a new list where each element is the sum of every
previous element (including itself) in the input order. The output has
the same length as the input.

Examples:
- running_sum([1, 2, 3, 4])  -> [1, 3, 6, 10]
- running_sum([5])           -> [5]
- running_sum([0, 0, 0])     -> [0, 0, 0]
- running_sum([])            -> []

Do not modify the input list. Do not change the signature.
