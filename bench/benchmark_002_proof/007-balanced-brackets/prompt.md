Fix the `is_balanced(s)` function in `buggy.py`. It returns True if
the brackets `()`, `[]` and `{}` in `s` are balanced and correctly
nested. All other characters are ignored.

Examples:
- is_balanced("a(b[c]{d})") -> True
- is_balanced("([)]") -> False
- is_balanced("(]") -> False
- is_balanced("") -> True
